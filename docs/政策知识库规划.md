# 政策知识库规划（AI政策通）

> 用途：填政策数据前的总纲。任何队友照着这张图，就知道"该找什么政策、归哪个部门、答案怎么写、原文怎么摘"。
> 版本：v1.0 ｜ 2026-08-21
> 配套数据表：`data/知识条目表.csv`（居民问的场景）＋ `data/官方文件表.csv`（官方原文）

## 6. 数据模型（两层，原文锁定）

原则：**事实来源 = 官方原文；通俗解答只是翻译层，不能当依据。**

**集合 `documents`（官方原文 · 事实基准）**
```
title       文件标题
source      发文机关
doc_no      文号（如 穗府办规〔2019〕X号）
publish_date 发布日期
source_url  出处链接
original_text 原文关键条款（逐字摘录，不改写）
```

**集合 `policies`（知识条目 · 检索与展示层）**
```
title        居民问的场景（如"公租房怎么申请"）
category     8 类之一
keywords[]   检索关键词
doc_ids[]    关联的原文文档 _id（一份原文可挂多个场景）
plain_answer 通俗解答（可选，标注"以原文为准"）
phone        咨询电话
venue        办理地点（社区服务类填具体地址，市局政策留空）
vector       由 title + keywords + plain_answer 生成
```

**ask 流程：**
```
问题 → 转向量 → 检索 policies Top4 → 按 doc_ids 拉原文
→ Prompt 拼原文：只准依据原文回答、不得编造、引用出处(标题+文号+链接)
→ GLM 生成 → answer + sources(标注资料来源)
```

## 7. 通俗解答质量标准（每条 150-250 字，5 段）

| 段 | 要求 |
|---|---|
| 谁能办 | 一句话对象（老人/学生/创业者/港澳青年/来穗…） |
| 要什么条件 | 核心条件 1-3 条（户籍/社保/收入/年限…） |
| 怎么办 | 线上哪个小程序（粤省事/粤税通/粤居码…）或线下哪个部门/街道 |
| 交什么材料 | 关键材料 2-4 项 |
| 注意 | 金额/时限加"以最新公告为准"；留 020-12345 或部门电话 |

纪律：口语化短句；不编造数字；拿不准写"以最新政策为准"；每条 ≥1 份真实出处链接。

---

## 8. 官方原文摘录标准

- 只摘**关键条款原文**（对象/条件/流程/标准），逐字复制，**不改写、不缩写大意**。
- 标题 + 文号 + 发布日期 + 链接必须写全，方便评审溯源。
- 链接优先官网（gz.gov.cn / thnet.gov.cn / 粤省事），不用二手转载。
