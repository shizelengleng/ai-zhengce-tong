# 云开发上云清单（P3 后端执行）

> 目的：把本地已就绪的数据和云函数部署到微信云开发，跑通第一条 AI 问答。
> 全程在**微信开发者工具**里点按钮，不需要写代码。卡住时截图发群里。

## 0. 前置确认（都已就绪）

| 材料 | 位置 | 说明 |
|---|---|---|
| 官方原文数据 | `data/documents.json` | 37 篇，JSON 数组，可直接导入 |
| 知识条目（含向量） | `data/policies_with_vector.json` | 37 条，每条含 1024 维 vector，可直接导入 |
| 4 个云函数 | `cloudfunctions/ask`、`getPolicies`、`saveHistory`、`getHistory` | 每个都有 `index.js` + `package.json`，依赖齐全 |

## 1. 打开项目 + 开通云开发

1. 微信开发者工具 → 导入项目 → 选择本仓库根目录 `xcx`（`project.config.json` 已配好 AppID `wxcbe9b5d978378d3b` 和云函数目录）
2. 顶部工具栏点 **「云开发」** → 首次会提示开通 → 按提示创建环境（名字随便起，如 `test`，选免费额度）
3. 开通后记下**环境 ID**（形如 `test-xxxx`），后面云函数会自动用当前环境，一般不用改

## 2. 建 3 个数据库集合

云开发控制台 → 左侧「数据库」→「新建集合」，依次建：

1. `documents`（官方原文）
2. `policies`（知识条目）
3. `conversations`（问答历史，空的即可）

> 集合名必须一模一样，云函数里写死了这几个名字。

## 3. 导入数据

**documents 集合**：
- 选中 `documents` → 右上角「导入」→ 选择 `data/documents.json` → 冲突处理选「Insert」→ 开始导入

**policies 集合**：
- 选中 `policies` → 「导入」→ 选择 `data/policies_with_vector.json` → 「Insert」→ 导入

导入后确认：`documents` 有 **37 条**、`policies` 有 **37 条**（集合名旁会显示数量）。

## 4. 部署 4 个云函数

微信开发者工具左侧「cloudfunctions」下，对每个云函数目录**右键** → 「上传并部署：云端安装依赖」：

1. `ask`
2. `getPolicies`
3. `saveHistory`
4. `getHistory`

> 一定要选「云端安装依赖」，否则 `ask` 里用到的 `axios` 装不上。

## 5. 给 ask 配置环境变量（12 个）

云开发控制台 → 云函数 → 选中 `ask` → 「配置」→「环境变量」→ 逐个添加：

> ⚠️ 真实密钥只放在本地 `.env`（含 `docs/ask环境变量.md`，已加入 .gitignore），**绝不 push 到 GitHub**（仓库是公开的）。下表只给变量名，值从本地 `.env` 复制。

| 变量名 | 值来源 |
|---|---|
| `DASHSCOPE_API_KEY` | 本地 `.env` 第 3 行 |
| `EMBEDDING_BASE_URL` | 本地 `.env` 第 8 行 |
| `EMBEDDING_MODEL` | `text-embedding-v4` |
| `EMBEDDING_DIM` | `1024` |
| `ZHIPU_API_KEY` | 本地 `.env` 第 11 行 |
| `ZHIPU_BASE_URL` | `https://open.bigmodel.cn/api/paas/v4` |
| `ZHIPU_MODEL_MAIN` | `glm-4.7-flash` |
| `ZHIPU_MODEL_FAST` | `glm-4-flash` |
| `SENSENOVA_BASE_URL` | `https://token.sensenova.cn/v1` |
| `SENSENOVA_KEYS` | 本地 `.env` 第 18 行 |
| `SENSENOVA_MODEL_DEEPSEEK` | `deepseek-v4-flash` |
| `SENSENOVA_MODEL_GLM` | `glm-5.2` |

保存后**重新部署一次** `ask`（右键 → 上传并部署），让环境变量生效。

## 6. 测试第一条问答

**方式一（推荐，最快）**：云函数控制台选中 `ask` → 点「云端测试」→ 输入：
```json
{ "question": "港澳青年子女怎么入读天河区小学？" }
```
点「运行」→ 看右侧返回的 `answer` 和 `sources` 是否正常。

**方式二（真机/模拟器）**：小程序里进「问答」页提问。但前端 `utils/api.js` 目前还是 mock，要接真后端需把注释里的 `wx.cloud.callFunction` 替换（P2 负责，等他改）。

## 常见问题

- **导入报「格式错误」**：确认选的是 JSON 文件，且是数组格式（本项目两个文件都是）。
- **运行报 `Cannot find module 'axios'`**：第 4 步没选「云端安装依赖」，重新上传部署。
- **报 `EMBEDDING_BASE_URL 未配置` 之类**：第 5 步环境变量没配全或没重新部署。
- **返回 `429`**：模型限流，属正常，代码会自动切换备选模型（glm-4-flash → sensenova）。
