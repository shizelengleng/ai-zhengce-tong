# 天河区扎实推进家庭医生签约服务 助力“百千万工程”再升级

发表时间：**2025-03-28 16:55:56**信息来源：**区卫生健康局**浏览量：**-**

**A+**大**A+**中**A+**小

![Image 2](http://www.thnet.gov.cn/img/1/1398/1398986/10189331.jpg)

为深入贯彻落实广州市优化家庭医生签约服务助推“百千万工程”提质增效十项措施，2025年3月27日，天河区卫生健康局在参加广州市卫生健康委召开的2025年广州市家庭医生签约服务工作推进会暨外配处方流转服务政策解读会后，随即套开2025年天河区家庭医生签约服务工作推进会议。天河区卫生健康局领导，局相关科室和各社区卫生服务机构及家庭医生签约项目负责人共88人齐聚一堂，共商家庭医生签约服务发展新路径。

会上，与会人员集中学习了广州市优化家庭医生签约服务助推“百千万工程”提质增效十项措施，以及一类门特外配处方流转服务有关政策。天河区社区卫生服务指导中心对2024年度天河区家庭医生签约服务工作进行了全面总结，结合提质增效十项措施及相关政策文件，明确部署了2025年家庭医生签约服务重点工作。天河区卫生健康局罗航乐副局长传达了市卫健委工作会议精神，对各社区卫生服务机构提出要求。最后，天河区卫生健康局局长唐德成作出重要指示：一是提高政治站位，提前统筹谋划。秉持为人民健康服务的理念，将年度重点工作细化，责任到人，确保各项工作指标有序推进，落实好优化基层药品配备等便民惠民措施，不断提升基层医疗卫生服务水平。二是坚持系统观念，做好签约服务。围绕广州市优化家庭医生签约服务助推“百千万工程”提质增效十项措施，以家庭医生签约为切入点，融合基本医疗和基本公共卫生服务，强化医防融合。此外，要加大对家庭医生的宣传力度，讲好家庭医生故事，提升居民知晓率和签约居民满意度。三是坚持问题导向，专项整改提升。针对重点工作、考核指标和现存问题，列出清单，制定方案，采取有效措施，集中力量解决问题，推动全区家庭医生签约服务高质量发展。

此次会议的召开，为天河区家庭医生签约服务工作指明了方向，天河区将以此次会议为契机，持续优化服务，推动“百千万工程”在基层卫生健康领域落地见效，为居民提供更优质、更便捷的健康服务。
