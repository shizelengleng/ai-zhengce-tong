# AI政策通 · UI改造计划书（融合版）

> **版本**：v1.0  
> **日期**：2026-08-26  
> **风格定位**：精致商务风（A）× 数据卡片风（B）融合方案  
> **改造范围**：问答页、分类页、详情页、我的页（全4页）+ 全局样式 + tabBar

---

## 一、设计理念

### 1.1 融合思路

本方案融合「精致商务风」与「数据卡片风」两大方向：

| 来源 | 吸收要素 |
|---|---|
| **A·精致商务** | 细腻排版层次、热门问题2列网格卡片、规范线性图标替代emoji、搜索栏置顶、卡片细边框+轻阴影、充足留白 |
| **B·数据卡片** | 顶部蓝色延伸区域+数据统计看板、最近问答列表、消息通知红点、政策更新数据标签、信息密度适中 |

### 1.2 核心气质

- **专业可信**：政务蓝主色调，稳重不花哨
- **信息高效**：数据看板 + 热门问题 + 最近问答，首页一屏掌握核心信息
- **精致现代**：规范图标、细腻阴影、合理间距，告别emoji和粗糙感
- **低改造成本**：在现有蓝色体系上深化，不推翻重构

## 二、设计规范

### 2.1 色彩体系

| 用途 | 色值 | 说明 |
|---|---|---|
| **主色-深** | `#1565C0` | 导航栏渐变起点、强调文字 |
| **主色-标准** | `#1E88E5` | 导航栏渐变终点、按钮、选中态 |
| **主色-浅** | `#E3F2FD` | 选中卡片背景、标签背景 |
| **辅助色-绿** | `#43A047` | 医疗分类、有效状态、成功 |
| **辅助色-橙** | `#FB8C00` | 社保分类、电话、办理方式 |
| **辅助色-紫** | `#8E24AA` | 住房分类 |
| **文字-主** | `#1A1A1A` | 标题、重要正文 |
| **文字-次** | `#555555` | 正文、说明 |
| **文字-弱** | `#888888` | 辅助信息、时间、占位 |
| **文字-禁用** | `#BBBBBB` | 禁用状态 |
| **背景-页面** | `#F5F7FA` | 页面底色 |
| **背景-卡片** | `#FFFFFF` | 卡片底色 |
| **背景-输入** | `#F0F2F5` | 输入框、搜索框底色 |
| **分割线** | `#E8E8E8` | 卡片内分割、列表分割 |
| **边框** | `#E0E0E0` | 卡片边框、输入框边框 |

### 2.2 字体规范

| 层级 | 字号(rpx) | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 40 | bold | 页面主标题、欢迎标题 |
| 标题 | 32 | bold/600 | 卡片标题、区块标题 |
| 正文 | 28 | regular | 主要内容、政策标题 |
| 辅助 | 24 | regular | 来源、时间、标签 |
| 小字 | 22 | regular | 数据标签、角标 |

- **字体族**：`-apple-system, "PingFang SC", "Helvetica Neue", Helvetica, sans-serif`
- **行高**：正文 1.6，标题 1.4

### 2.3 间距与圆角

| 元素 | 数值(rpx) |
|---|---|
| 页面左右边距 | 24 |
| 卡片内边距 | 28~32 |
| 卡片间距 | 20~24 |
| 元素间距（小） | 8~12 |
| 元素间距（中） | 16~20 |
| 卡片圆角 | 16 |
| 按钮/输入框圆角 | 999（胶囊）/ 20 |
| 标签圆角 | 999（胶囊） |
| 图标圆角 | 50%（圆形） |

### 2.4 阴影规范

| 层级 | 阴影值 | 用途 |
|---|---|---|
| 轻阴影 | `0 2rpx 8rpx rgba(0,0,0,0.04)` | 普通卡片、列表项 |
| 中阴影 | `0 4rpx 16rpx rgba(0,0,0,0.06)` | 分类卡片、弹窗 |
| 蓝阴影 | `0 4rpx 12rpx rgba(30,136,229,0.15)` | 主按钮、选中卡片 |

### 2.5 图标规范

- **全部替换emoji为线性图标**（使用 iconfont 或 SVG 内联）
- 图标风格：2px 描边、圆角端点、统一视觉重量
- 尺寸：导航栏 36rpx，卡片图标 44~48rpx，tabBar 40rpx
- 颜色：导航栏白色，tabBar 选中 `#1E88E5` / 未选中 `#999`

> **注意**：微信小程序原生导航栏不支持渐变。如需深蓝渐变导航栏，有两种方案：

> - **方案二**：保持原生导航栏，使用纯色 `#1565C0`，在页面内部顶部加渐变延伸区域模拟

## 八、风险与注意事项

1. **自定义导航栏风险**：如使用 `navigationStyle: custom`，需手动处理状态栏高度、胶囊按钮避让、各页面适配，工作量增加约30%。建议初期使用纯色导航栏 `#1565C0` + 页面内渐变延伸区，降低风险。

2. **tabBar图标限制**：微信小程序tabBar图标必须使用本地PNG图片，不支持SVG和网络图片。需提前准备好3组图标（未选中/选中），尺寸81px×81px。

3. **数据看板数据来源**：累计问答、政策库数量、好评率等数据需要后端接口支持。如暂无接口，可先用静态数据占位，后续对接。

4. **热门问题/热门政策数据**：需要配置热门问题列表和热门政策排名数据。可先在前端硬编码，后续移至云开发数据库。

5. **图标版权**：使用iconfont等平台的图标需注意版权协议，建议使用免费可商用图标库（如Iconfont阿里巴巴矢量图标库的免费图标、Remix Icon、Lucide等）。
