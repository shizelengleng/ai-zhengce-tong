## 一、项目概述

**「AI政策通」** 是一款基于微信小程序的社区便民 AI 应用。它把天河区复杂、专业的政策文件转化为通俗易懂的对话式问答，居民用日常口语提问即可获得精准解答，并附官方出处与办事入口。

**解决的核心痛点**：「人找政策」模式下信息获取难、理解成本高。

**项目目标**：在 **2026-08-31 24:00** 前完成可演示的小程序 MVP，并提交完整参赛材料。

**参赛对标**：
- 板块：板块二·AI应用创新·数智天河
- 方向：方向1·社区便民（政策科普）
- 参考奖项：一等奖 10000 元 / 二等奖 5000 元 / 三等奖 2000 元 / 最佳落地应用奖 2000 元

## 二、产品设计

### 2.1 产品定位

> 把天河区海量政策文件，变成人人能问、一问就懂、还带办事入口的"政策百晓生"。

### 2.2 目标用户

| 用户画像 | 典型诉求 |
|---|---|
| 港澳青年家长 | 孩子能否入读天河区公立学校、需要什么条件 |
| 新市民/来穗人员 | 居住证、入户、社保如何办理 |
| 创业者/小微企业 | 创业补贴、担保贷款、场地扶持 |
| 老年居民子女 | 帮父母问医保、养老服务 |

### 2.3 核心功能（MVP）

1. **对话式问答**：口语提问 → AI 给出通俗答案 + 政策出处 + 办事入口
2. **政策分类浏览**：教育 / 医疗 / 住房 / 就业创业 / 社保补贴 / 港澳青年
3. **政策详情页**：通俗解读 + 官方出处 + 咨询电话 + 办理链接
4. **问答历史**：历史记录云端保存，可回看

### 2.4 差异化亮点（评审加分项）

- 答案**可溯源**：每条回复附官方出处链接，解决 AI 编造问题
- 数据**全部为天河区真实政策**，紧扣比赛主题
- 内置**演示脚本**：现场演示 3-5 个典型问题（港澳子女入学、创业补贴等）

## 三、产品与技术选型（用哪些产品）

### 3.1 选型总览

| 环节 | 选用产品 | 作用 | 成本 |
|---|---|---|---|
| 前端 | 微信原生小程序（微信开发者工具） | 用户界面与交互 | 免费 |
| 后端 | 微信云开发（云函数 + 云数据库 + 云存储） | 免服务器托管、数据存储、AI 中转 | 免费额度 |
| 大模型(生成) | 智谱 GLM-4-Flash | 生成政策问答答案 | 免费 |
| Embedding(检索) | 阿里云百炼 text-embedding-v4 | 政策/问题向量化，语义检索 | 免费 100 万 token/90 天 |
| 备选模型 | DeepSeek chat | 免费额度用尽时兜底 | 约 1-2 元/百万 token |
| 协作工具 | 腾讯文档 | 共享政策数据、进度跟踪 | 免费 |
| 代码版本 | Git / 简单压缩包备份 | 防止误删 | 免费 |

### 3.2 为什么这样选

| 对比项 | 传统方案（自建服务器） | 本方案（云开发） |
|---|---|---|
| 服务器 | 需购买/租赁 | 无需，云函数按调用计费 |
| 域名备案 | 需要 ICP 备案 | 不需要 |
| HTTPS | 需要配置证书 | 云开发内置 |
| 小程序合法域名白名单 | 需要备案域名 | 云函数外呼不受限 |
| 上手难度 | 高 | 低 |

### 3.3 各产品角色说明

- **微信开发者工具**：唯一的开发环境，写代码、调试、真机预览、录屏演示都在这里完成。
- **云开发**：提供 `wx.cloud.callFunction`，小程序前端直接调用云函数；云数据库存政策与对话记录；云存储存附件/二维码。
- **智谱开放平台**：提供免费的 GLM-4-Flash API（OpenAI 兼容格式），负责**生成答案**，云函数里用 HTTP 请求调用。
- **阿里云百炼**：提供免费的 text-embedding-v4 向量化接口（OpenAI 兼容格式），负责**把政策与问题转成向量**做语义检索，构成 RAG 的"检索"环节。
- **腾讯文档**：三人共享政策整理表，一人负责汇总为 JSON 灌入数据库。

## 四、系统架构

```
┌─────────────────────────────────────┐
│       微信小程序（原生 WXML/WXSS/JS）    │
│   chat 聊天  ·  category 分类          │
│   detail 详情 · mine 我的              │
└────────────────┬────────────────────┘
                 │ wx.cloud.callFunction
┌────────────────▼────────────────────┐
│   微信云开发·云函数（Node.js）           │
│                                      │
│   ask()          向量检索 → 拼接Prompt   │
│                  → 调用大模型 → 返回答案   │
│   getPolicies()  政策分类/详情查询       │
│   save/getHistory 问答历史存取          │
└───────┬──────────────────┬──────────┘
        │                  │
┌───────▼───────┐   ┌──────▼──────────┐
│  云数据库       │   │  智谱 GLM-4-Flash │
│  policies      │   │  (免费大模型API)   │
│  conversations │   └─────────────────┘
└───────────────┘
```

**数据流（一次问答）**：
1. 用户在聊天页输入问题
2. 前端调用云函数 `ask`，传入 `question`
3. 云函数将用户问题调 Embedding API 转为向量
4. 云函数在 `policies` 中做**向量语义检索**（余弦相似度），取最相关的 3-5 条
5. 云函数将命中的政策拼接进系统提示词（Prompt）
6. 云函数调用智谱 GLM-4-Flash 生成答案
7. 返回答案文本 + 出处，前端渲染为气泡

## 六、后端与数据设计

### 6.1 云函数设计

| 云函数 | 输入 | 输出 | 职责 |
|---|---|---|---|
| `ask` | `{ question }` | `{ answer, sources[] }` | 向量检索 + Prompt + 调模型 |
| `getPolicies` | `{ category?, id? }` | `{ policies[] }` | 分类列表 / 详情 |
| `saveHistory` | `{ question, answer }` | `{ success }` | 存历史 |
| `getHistory` | 无 | `{ history[] }` | 读历史 |

### 6.2 云数据库集合

**policies（政策知识库）**
```
{
  _id: "xxx",
  category: "education",        // 分类
  title: "天河区公办小学入学条件",
  keywords: ["小学", "入学", "公立", "港澳", "随迁"],
  summary: "通俗易懂的解答正文……",
  source: "天河区教育局",        // 官方出处
  source_url: "https://…",      // 出处链接
  phone: "020-xxxx",            // 咨询电话
  tags: ["教育", "入学"],
  vector: [0.001, 0.002, ...],  // 1024维向量（批量脚本调用Embedding自动生成）
}
```

**conversations（问答历史）**
```
{
  _id: "xxx",
  openid: "用户标识",
  question: "孩子想读天河公立小学……",
  answer: "……",
  policy_ids: ["xxx"],
  create_time: "2026-08-20 12:00"
}
```

### 6.3 Prompt 设计（决定回答质量）

固定系统提示词：

> 你是"天河区政策助手"。请只依据下面提供的政策资料回答问题，不得编造。先给出通俗答案，再列出依据与官方出处链接。若资料中没有相关内容，明确说明"建议拨打 12345 咨询"。回答使用简体中文，语言亲切易懂。

## 七、核心环节：政策知识库

### 7.1 为什么它最重要

知识库决定答案质量，是"真实、本地化、可溯源"的基础，也是评审看重的地方。技术环节全部可复用模板，**资料整理最耗时、最不可替代**。

### 7.2 数据来源（官方渠道）

- 天河区政府门户网站
- 「天河发布」「青春天河」微信公众号
- 广州 12345 政务服务
- 粤省事 / 穗好办
- 广州市教育局等主管部门官网

### 7.3 目标规模与分类

**30-50 条真实政策**，每类 5-8 条：

| 分类 | 样例 |
|---|---|
| 教育入学 | 公办小学/初中入学、随迁子女入学、港澳居民子女就读 |
| 医疗保障 | 医保参保、异地就医备案、家庭医生 |
| 住房保障 | 公租房、人才公寓、租赁补贴 |
| 就业创业 | 创业担保贷款、一次性创业补贴、港澳青年创业扶持 |
| 社保补贴 | 灵活就业参保、社保卡申领、见习补贴 |
| 政务办事 | 居住证、人才引进入户、营业执照 |

### 7.4 每条政策的字段规范

每一条必须填齐：`标题`、`关键词`、`通俗答案`、`官方出处`、`出处链接`、`咨询电话`。`vector` 向量字段由批量脚本调用 Embedding API 自动生成，无需手工填写。
