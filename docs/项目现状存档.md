## 3. 产品

- **定位**：把天河区海量政策文件，变成"人人能问、一问就懂、带办事入口"的政策百晓生。
- **目标用户**：港澳青年家长、来穗新市民、创业者、老年居民子女。
- **核心功能（MVP）**：对话问答 / 政策分类浏览（6类）/ 政策详情 / 问答历史。
- **页面**：`chat`（聊天）· `category`（分类）· `detail`（详情）· `mine`（我的）。
- **差异化亮点**：答案**可溯源**（附官方出处）、数据全部为**天河真实政策**、内置**演示脚本**。

## 4. 技术方案（已确认）

```
用户提问 → 云函数ask → 问题转向量 → 向量检索Top3-5
        → 拼Prompt → 智谱GLM生成 → 答案+出处
```

- **前端**：微信原生小程序（微信开发者工具），不引第三方 UI 库。
- **后端**：微信云开发（云函数 + 云数据库 + 云存储），免服务器、免域名备案、外呼 API 不受域名白名单限制。
- **RAG 检索**：阿里云百炼 `text-embedding-v4`（1024 维，OpenAI 兼容接口）。知识库几十条，云函数内存算余弦相似度即可，**不需要向量数据库**。
- **回答生成**：智谱 GLM。主力 `glm-4-flash`（快）；备选 `glm-4.7-flash`（推理型，`max_tokens` 需调到 1024+，回答更慢但质量高）；兜底 SenseNova `deepseek-v4-flash` / `glm-5.2`。
- **云函数清单**：`ask`（向量检索+Prompt+调模型）、`getPolicies`（分类/详情）、`saveHistory`、`getHistory`。
- **数据库集合**：`documents`（官方原文）、`policies`（知识条目，含 `doc_ids`、`vector` 字段）、`conversations`（问答历史）。
- **Prompt 原则**：只依据提供的政策资料回答、不得编造、给出处、无匹配时引导拨打 12345。
