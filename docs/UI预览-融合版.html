小学入学报名需要什么材料？
🤖
您好！天河区小学入学报名需要以下材料：

1. 户口簿原件及复印件
2. 儿童出生医学证明
3. 预防接种证
4. 房产证或租房合同
5. 家长身份证

具体要求以当年招生政策为准。

天河区2024年小学招生工作方案
教育入学 招生 小学
📖 政策解读

线上：粤省事小程序 → 入学报名
线下：天河区政务服务中心（天河区软件路13号）
